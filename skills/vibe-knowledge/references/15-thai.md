# 15 · โหมดภาษาไทย (`--lang th`)

สรุปทุกอย่างที่เปลี่ยนเมื่อทำคลิปภาษาไทย ส่วนที่ไม่ได้พูดถึงในหน้านี้ทำงานเหมือนฉบับจีนทุกอย่าง (แม่แบบ 6 แบบ สไตล์ บัญชีข้อเท็จจริง การตรวจแบบหาจุดอ่อน BGM บังคับ คิวเรนเดอร์ ฯลฯ)
（泰语模式总览：只列和中文版不同的地方，其余流程照旧。）

## 1. เริ่มตอนใหม่

```bash
export VK_WORKSPACE=~/vibe-knowledge          # ค่าเริ่มต้นอยู่แล้ว อย่าวางไว้บน ~/Desktop (iCloud อาจย้ายไฟล์ออกระหว่างเรนเดอร์)
python3 skills/vibe-knowledge/tools/new_film.py 01 --template C --title "ก๋วยเตี๋ยวห้าบาทหายไปไหน" --lang th --series vk-th
python3 skills/vibe-knowledge/tools/recommend.py "ก๋วยเตี๋ยวชามละห้าบาทหายไปไหน"        # แนะนำสไตล์จากคำไทย
python3 skills/vibe-knowledge/tools/duration.py --scores 1,0,2,1,1 --template C --lang th   # งบตัวอักษรตามความเร็วเสียงจริง
```

`--lang th` ให้ได้ narration.json จาก `templates/narration/th/` (เสียง say Kanya, `voice.lang: "th"`), film.js จาก `film.skeleton.th.js` และ facts.md ภาษาไทย แนะนำให้แยกซีรีส์ (`--series vk-th`) จากซีรีส์ภาษาจีน

## 2. หน่วยนับ: ตัวอักษรที่แสดงผล

ทุกที่ที่ฉบับจีนนับ "字" ฉบับไทยนับ **ตัวอักษรที่แสดงผล** = กลุ่มอักขระ (grapheme cluster) ไม่นับช่องว่างและเครื่องหมายวรรคตอน สระบน สระล่าง วรรณยุกต์ การันต์ และสระอำ ติดไปกับพยัญชนะตัวที่อยู่ด้วย
`ที่นี่` = 2 · `กำลัง` = 3 · `เขียน` = 4 · `น้ำ` = 1 · `ภาษาไทย` = 7
Python ใช้ `ai-teardown/engine/scripts/thtext.py` เบราว์เซอร์ใช้ `Intl.Segmenter` (ใน `cine/engine/util.js`: `thLen`) สองฝั่งให้ผลตรงกัน `selftest_th.py` ตรวจเรื่องนี้ทุกครั้ง

| กติกา | ภาษาจีน | ภาษาไทย | ที่มาของตัวเลข |
|---|---|---|---|
| คีย์เวิร์ดบนจอ | ≤ 8 字 | ≤ 14 ตัวอักษร (`KW_MAX_TH`) | ตัวไทยกว้างราว 0.55–0.6 ของตัวจีน 8 ตัวจีนจึงกว้างเท่าไทยราว 13–15 ตัว และเวลาอ่านเมื่อเทียบความเร็วพูดก็อยู่ที่ 12–17 |
| ซับไตเติลต่อบรรทัด | ≤ 16 字 | ≤ 30 ตัวอักษร (`TH_SUB_MAX`) | อ่านทัน 2.5–4 วินาทีที่ความเร็ว 8–13 ตัว/วินาที ใกล้กับ 16 字 ที่ 5.5 字/วินาที |
| ความยาวบทพูดต่อช่วง | ตามแม่แบบ | ตัวเลขจีน × 8.2 ÷ 5.75 | รักษาเวลาเท่าเดิม (ความเร็ว say ที่วัดได้ ÷ ความเร็วคลิปจีน) |

## 3. เสียงพากย์ (`scripts/tts_th.py`)

| backend | ฟรี? | ออฟไลน์? | เวลาระดับคำ | ความเร็ววัดจริง | ข้อควรรู้ |
|---|---|---|---|---|---|
| `say` (Kanya) ค่าเริ่มต้น | ✔ | ✔ | ✘ (แบ่งตามสัดส่วน) | 7.2–8.8 เฉลี่ย 8.2 ตัว/วิ | **สัญญาอนุญาต macOS ให้ใช้เสียงระบบเฉพาะงานส่วนตัวที่ไม่ใช่เชิงพาณิชย์ และห้ามเผยแพร่สาธารณะ** ใช้ทำร่าง จับเวลา พรีวิว แล้วพากย์ใหม่ก่อนโพสต์ |
| `edge` (Niwat / Premwadee) | ✔ | ✘ | ✔ WordBoundary | ชาย 11.2–12.4 (11.6) · หญิง 11.9–14.4 (13.1) | เรียกบริการอ่านออกเสียงของ Microsoft Edge แบบไม่เป็นทางการ ข้อความถูกส่งไป Microsoft อาจเปลี่ยนหรือหยุดได้ทุกเมื่อ เงื่อนไขการใช้งานเชิงพาณิชย์ไม่ชัดเจน ตรวจเองก่อนใช้ |
| `gemini` | ฟรีในระดับฟรี (คีย์ของคุณเอง) | ✘ | ✘ | ยังไม่ได้วัด | โมเดล `gemini-3.8-flash-tts` (ตามเอกสาร Gemini API ที่ดึงมาเมื่อ 3 พ.ย. 2026) ระดับฟรีไม่เสียเงินแต่จำกัดอัตราต่อโปรเจกต์ และหน้าราคาระบุว่าข้อมูลในระดับฟรีถูกใช้ปรับปรุงผลิตภัณฑ์ ยังไม่ได้ทดสอบจริงเพราะไม่มีคีย์ |
| `mimo` | ตามโปรโมชันของผู้ให้บริการ | ✘ | ✘ | ยังไม่ได้วัด | ใช้คีย์และ API เดียวกับ tts_mimo.py ยังไม่ได้ยืนยันว่าอ่านภาษาไทยได้ดี |

```bash
python3 scripts/tts_th.py $L/narration.json $L/build --gap 0.2 --lead 0.3                 # say (ร่าง)
python3 scripts/tts_th.py $L/narration.json $L/build --backend edge --qa                   # edge + ตรวจฟังกลับ
python3 scripts/speed.py $L 1.1 && (cd $S && python3 tools/check_timings.py <ตอน>) && python3 ~/.claude/skills/vibe-knowledge/tools/voice_post.py $L
```

- เวลา `[[cue]]` แบบสัดส่วน: เทียบกับเวลาจริงของ edge บน 6 ย่อหน้า ต้นคำคลาดเฉลี่ย 0.23 วินาที 90% อยู่ภายใน 0.56 วินาที มากสุดราว 1.1 วินาที ช็อตที่ต้องตรงจังหวะมากให้พากย์ด้วย edge หรือขยับใน film.js เช่น `T("B03.cue+0.2")`
- ตัวเลขในบทพูด: ตัวเลขอารบิกบนจอสั้น แต่เวลาอ่านยาว (`2026` = สองพันยี่สิบหก) ย่อหน้าที่มีตัวเลขช้ากว่าค่าเฉลี่ยราว 10–12% ถ้าอยากควบคุมการอ่านให้เขียนเป็นคำ หรือใส่ `lexicon`
- คำอังกฤษ/ตัวย่อ: ใส่ `lexicon` เช่น `{"AI": "เอไอ"}` (edge จะคืนเวลาของคำที่อ่านจริงแล้วแมปกลับมาที่ข้อความเดิมให้)
- `--qa` ฟังกลับด้วย faster-whisper ภาษาไทย ให้คะแนนตาม "เสียง" ไม่ใช่การสะกด (Whisper สะกดไทยตามเสียง) ต่ำกว่า 80% ให้ไปฟังช่วงนั้น บนข้อความทดสอบ 18 ย่อหน้า เสียงทั้งสามได้ 82–99%
- ความเร็วเสียง: `measure_th_rate.py` วัดใหม่ได้ทุกเมื่อ ถ้าเปลี่ยน `say -r` หรือ edge `--rate` ให้วัดใหม่แล้วใช้ `duration.py --cps`

## 4. ภาพ ตัวอักษร และการตัดบรรทัด

- เอนจิน cine มีฟอนต์ **Noto Sans Thai** (OFL) มาในตัว ข้อความที่มีอักษรไทยได้คลาส `.th` อัตโนมัติจาก `el()` ซึ่งตั้ง `letter-spacing: 0` (ระยะห่างตัวอักษรทำให้สระ/วรรณยุกต์แยกจากพยัญชนะ) และใช้ Noto Sans Thai ก่อน
- ข้อความไทยตัดบรรทัดเฉพาะที่ขอบคำ (`Intl.Segmenter`) ไม่ตัดกลางคำหรือกลางพยางค์
- ซับไตเติลภาษาไทยแบ่งตามวรรค (ช่องว่าง) แล้วรวมให้ยาวไม่เกิน 30 ตัวอักษร วลีที่ยาวเกินถูกตัดที่ขอบคำ
- อย่าวาดข้อความไทยด้วย PIL: PIL ที่ไม่มี libraqm วางสระบน/ล่างผิดตำแหน่ง ปกคลิปหรือภาพที่มีตัวไทยให้ทำผ่านเบราว์เซอร์ (`cine/tools/stills.py`) เสมอ
- ภาพที่สร้างด้วย AI มักเขียนตัวไทยผิด ใส่ `no text, no letters` ในพรอมต์ แล้วให้โค้ดเขียนข้อความทับ
- `vquote` (ข้อความแนวตั้งทีละตัว) ออกแบบมาสำหรับอักษรจีนโบราณ ไม่เหมาะกับภาษาไทย

## 5. สไตล์ไทย

สามสไตล์ใหม่ในกลุ่ม "ไทย": `thaimural` (จิตรกรรมฝาผนัง ต้องสร้างภาพ), `nangtalung` (หนังตะลุง โค้ดล้วน), `thaisign` (ป้ายร้านตลาดย้อนยุค โค้ดล้วน) ยังไม่มีภาพตัวอย่าง (`still.jpg` เป็น TODO) และยังไม่ได้เรนเดอร์ตัวอย่าง ทุกสไตล์เดิมมีชื่อ คำอธิบาย และคีย์เวิร์ดภาษาไทยใน `styles/catalog.json` แล้ว

## 6. ระดับเพิ่มพลังโดยไม่ต้องใช้ Renoise

ช็อตเพิ่มพลังต้องการแค่ไฟล์ภาพหรือคลิป สร้างด้วยเครื่องมืออะไรก็ได้ แล้วบันทึกใน `assets.json` ช่อง `engine` (`manual` / `codex-imagen` / `grok` / `comfyui` / `renoise`) ขั้นตอนอยู่ใน 04-renoise.md หัวข้อ "自带生成器" ทุกภาพติดป้าย `tag: "ภาพ AI"`

## 7. ตรวจงานและเผยแพร่

- `qa.py <คลิป.mp4> --lang th`: OCR ด้วย Apple Vision `th-TH` ใช้เทียบข้อความบนจอกับ facts.md (ตัวยก เช่น 2⁴² จะอ่านเป็น 242 ให้เทียบด้วยตา)
- qa.py ตรวจ BGM โดยเทียบช่วงต้นคลิปกับต้นเพลง คลิปที่สั้นมาก (ราว 20 วินาทีลงไป) fit_bgm ตัดหัวเพลงสั้นจน qa.py อาจเตือนว่าไม่มี BGM ทั้งที่มี ปัญหานี้มีในต้นฉบับอยู่แล้ว ให้ดู `build/bgm.json` ประกอบ
