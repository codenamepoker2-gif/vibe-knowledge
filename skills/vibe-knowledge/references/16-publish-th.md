## 1. สัดส่วนภาพ

เอนจินเรนเดอร์ 16:9 (1920×1080) เท่านั้น สำหรับ YouTube ปกติและ Facebook แนวนอนใช้ได้เลย ถ้าจะลง TikTok / Reels / Shorts ที่เป็นแนวตั้ง มีสองทาง:

**ก. วางกลางบนพื้นเบลอ (แนะนำ ไม่เสียข้อความ)** ทดสอบกับคลิปตัวอย่างแล้ว ได้ 1080×1920 ความยาวเท่าเดิม เสียงไม่ถูกเข้ารหัสใหม่

```bash
ffmpeg -i lesson01.mp4 -filter_complex \
 "[0:v]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,boxblur=24:6,eq=brightness=-0.12[bg];\
  [0:v]scale=1080:-2[fg];[bg][fg]overlay=(W-w)/2:(H-h)/2,format=yuv420p" \
 -c:v libx264 -crf 20 -preset medium -c:a copy -movflags +faststart lesson01_9x16.mp4
```

ภาพหลักจะเหลือกว้าง 1080 ตัวหนังสือเล็กลงราวครึ่งหนึ่ง ถ้ารู้ตั้งแต่แรกว่าจะลงแนวตั้งเป็นหลัก ให้ใช้คีย์เวิร์ดขนาด 120px ขึ้นไป ซับไตเติลเดิมอยู่ช่วงล่างของแถบกลาง ยังอ่านได้บนมือถือ

**ข. ครอปกลาง** (`scale=-2:1920,crop=1080:1920`) ภาพเต็มจอแต่ซ้ายขวาหายไปราว 70% เหมาะเฉพาะฉากที่จัดองค์ประกอบไว้กลางจอ ซับไตเติลและเชิงอรรถมักถูกตัด ไม่แนะนำ

แม่แบบ C (ปัญหาใกล้ตัว + หลักการ) และ F (หกมุมมอง 45–60 วินาที) เหมาะกับคลิปสั้นแนวตั้งที่สุด

## 2. ชื่อคลิป คำบรรยาย แฮชแท็ก

- **ชื่อ/บรรทัดแรก**: เอาคำถามฮุกขึ้นก่อน ภาษาพูด สั้น อ่านจบในครั้งเดียว เช่น `ทำไมบัญชีปลอมถึงโดนจับได้จากเลขตัวแรก?` อย่าเปิดด้วยชื่อช่องหรือคำว่า "EP."
- **คำบรรยาย**: บรรทัดแรกซ้ำฮุก บรรทัดที่สองบอกที่มาอย่างย่อ ("ข้อมูลอ้างอิงอยู่ในคลิปและในคอมเมนต์") บรรทัดสุดท้ายถามคำถามปิดท้ายของคลิปเพื่อชวนคอมเมนต์ ใส่แหล่งอ้างอิงเต็มจาก facts.md ในคอมเมนต์ปักหมุด
- **แฮชแท็ก 3–5 อัน**: หนึ่งอันกว้าง หนึ่งถึงสองอันตามหมวด หนึ่งอันเฉพาะเรื่อง เช่น `#รู้หรือไม่ #ความรู้รอบตัว #วิทยาศาสตร์ #กฎของเบนฟอร์ด` แท็กหมวดที่คนไทยใช้บ่อย: `#ประวัติศาสตร์ #วิทยาศาสตร์ #การเงิน #สุขภาพ #เทคโนโลยี` (แท็กแคมเปญของแพลตฟอร์มเปลี่ยนตามช่วงเวลา ตรวจในแอปก่อนใช้)
- **การสะกด**: ชื่อเฉพาะและคำทับศัพท์ให้ตรงกับที่ใช้บนจอและในบทพูด ถ้ามีหลักเกณฑ์ราชบัณฑิตยสภาให้ยึดตามนั้น
- **ปก**: ทำผ่าน `stills.py` แล้ว `cover_first.py` (อย่าเขียนตัวไทยบนปกด้วย PIL ดู 15-thai.md ข้อ 4) แพลตฟอร์มแนวตั้งให้ทำปกจากคลิป 9:16 แยกอีกครั้ง

## 3. ติดป้ายเนื้อหาที่สร้างด้วย AI

คลิปจากเครื่องมือนี้มี **เสียงสังเคราะห์** และอาจมี **ภาพที่สร้างด้วย AI** ทั้งสามแพลตฟอร์มมีตัวเลือกให้ผู้โพสต์ระบุเนื้อหา AI ตอนอัปโหลด และมีนโยบายบังคับให้ระบุเมื่อเนื้อหาดูสมจริง:

- **TikTok**: ตอนโพสต์มีสวิตช์ระบุว่าเป็นเนื้อหาที่สร้างด้วย AI (AI-generated content) ภาพหรือเสียงสมจริงที่สร้างด้วย AI ต้องติดป้าย
- **YouTube (รวม Shorts)**: ใน YouTube Studio มีคำถามเรื่อง "altered or synthetic content" ตอนอัปโหลด ต้องตอบว่าใช่เมื่อเนื้อหาสมจริงอาจทำให้คนเข้าใจผิดว่าเป็นของจริง
- **Facebook / Instagram Reels (Meta)**: มีตัวเลือกติดป้าย "AI info" ตอนโพสต์ และ Meta ระบุให้ผู้โพสต์เปิดเผยเมื่อวิดีโอหรือเสียงที่ดูสมจริงถูกสร้างหรือดัดแปลงด้วยดิจิทัล

แนวปฏิบัติของโปรเจกต์นี้ (เข้มกว่าที่แพลตฟอร์มบังคับ): เปิดตัวเลือก AI ทุกครั้งที่มีเสียงสังเคราะห์หรือภาพ AI, ติดป้าย "ภาพ AI" ที่มุมภาพทุกช็อตที่สร้างขึ้น (plate / vclip ทำให้อยู่แล้ว เปลี่ยนข้อความด้วย `tag: "ภาพ AI"`) และใส่ในคำบรรยายว่า "เสียงบรรยายสังเคราะห์ด้วย AI"

## 4. สิทธิ์ของเสียงและเพลงก่อนโพสต์

- **เสียง `say` (Kanya)**: สัญญาอนุญาต macOS ระบุว่าใช้เสียงระบบได้เฉพาะงานส่วนตัวที่ไม่ใช่เชิงพาณิชย์ และห้ามเผยแพร่ในบริบทสาธารณะ ก่อนโพสต์ให้พากย์ใหม่ด้วย backend อื่นหรือเสียงของคุณเอง
- **edge-tts**: เป็นการใช้บริการของ Microsoft แบบไม่เป็นทางการ เงื่อนไขเชิงพาณิชย์ไม่ชัดเจน ประเมินความเสี่ยงเอง
- **BGM เริ่มต้น** (`vibe-bgm.m4a`): ผู้เขียนต้นฉบับระบุว่าใช้ได้ในวิดีโอที่ทำด้วยเครื่องมือนี้ ห้ามแยกไปแจกหรือขาย (ดู NOTICE.th.md) แพลตฟอร์มอาจตรวจจับลิขสิทธิ์เพลงผิดพลาดได้ ให้เก็บหลักฐานที่มาไว้
