## นี่คืออะไร

ฉบับนี้แยกมาจาก [vibe-knowledge](https://github.com/andyhuo520/vibe-knowledge) ซึ่งเดิมทำคลิปภาษาจีนอย่างเดียว เราเพิ่มโหมดภาษาไทยเข้าไปโดยไม่แตะพฤติกรรมเดิม: ถ้าไม่ใส่ `--lang th` ทุกอย่างยังเป็นภาษาจีนเหมือนต้นฉบับ

หลักคิดยังเหมือนเดิม:

- **ไม่มีแหล่งอ้างอิง ไม่ขึ้นจอ** ตัวเลข ชื่อคน ปี คำพูด ต้องอยู่ในบัญชีข้อเท็จจริง (`facts.md`) ก่อน
- **บทพูดเล่าเรื่อง ภาพให้คีย์เวิร์ด** ประโยคยาวปล่อยให้เสียงกับซับไตเติล บนจอมีแค่คำสั้น ๆ
- **ทำด้วยโค้ดก่อน** ภาพส่วนใหญ่วาดด้วยโค้ด (SVG, อนุภาค, 3D, กราฟ) มีแค่ไม่กี่ช็อตที่ต้องใช้ภาพหรือคลิปที่สร้างขึ้น
- ทุกคลิป = **แม่แบบการเล่า (6 แบบ) × สไตล์ภาพ (47 แบบ) × ระดับ** (โค้ดล้วน / เพิ่มพลังด้วยภาพที่สร้างเอง)

## มีอะไรใหม่ในฉบับภาษาไทย

| เรื่อง | สิ่งที่ทำ |
|---|---|
| การนับตัวอักษร | นับเป็น "ตัวอักษรที่แสดงผล" (grapheme cluster) ไม่นับสระบนล่าง วรรณยุกต์ ช่องว่าง ฝั่ง Python กับเบราว์เซอร์นับตรงกัน |
| เสียงพากย์ | `tts_th.py` ใช้เสียงฟรีได้: `say` (Kanya, ออฟไลน์), `edge-tts` (เสียงนิวรัล), Gemini (คีย์ของคุณ), MiMo |
| ความเร็วพูด | วัดจริงจากเสียงแต่ละตัว แล้วใช้คำนวณความยาวบทใน `duration.py --lang th` |
| ตัวอักษรบนจอ | ฝัง Noto Sans Thai, ตั้ง letter-spacing เป็น 0 อัตโนมัติ, ตัดบรรทัดที่ขอบคำ, ซับไตเติลแบ่งตามวรรค |
| แม่แบบ | บทพูดทั้ง 6 แบบ, บัญชีข้อเท็จจริง, โครง film.js เป็นภาษาไทย |
| สไตล์ | ทุกสไตล์มีชื่อและคีย์เวิร์ดภาษาไทย แนะนำสไตล์จากหัวข้อภาษาไทยได้ เพิ่มสไตล์ไทย 3 แบบ |
| ระดับเพิ่มพลัง | ไม่ผูกกับ Renoise แล้ว สร้างภาพหรือคลิปด้วยเครื่องมือไหนก็ได้ แล้ววางไฟล์เข้าโปรเจกต์ |
| ตรวจงาน | OCR ภาษาไทย (`th-TH`), ฟังกลับด้วย faster-whisper, `selftest_th.py` |
| เผยแพร่ | คู่มือ TikTok / Facebook Reels / YouTube Shorts, แปลงเป็น 9:16, การติดป้ายเนื้อหา AI |
| โฟลเดอร์ทำงาน | ใช้ `$VK_WORKSPACE` (ค่าเริ่มต้น `~/vibe-knowledge`) ไม่ใช้ `~/Desktop` เพราะบน macOS เดสก์ท็อปมักซิงก์กับ iCloud แล้วไฟล์อาจถูกย้ายออกระหว่างเรนเดอร์ |

## เริ่มใช้

```bash
git clone <ที่อยู่ของรีโพนี้> vibe-knowledge-th
cp -R vibe-knowledge-th/skills/vibe-knowledge vibe-knowledge-th/skills/ai-teardown ~/.claude/skills/

# Python สำหรับเรนเดอร์ (numpy scipy pillow playwright)
python3 -m venv ~/.venvs/cine && ~/.venvs/cine/bin/pip install numpy scipy pillow playwright
~/.venvs/cine/bin/python -m playwright install chromium-headless-shell
export CINE_PY=~/.venvs/cine/bin/python
```

ต้องมี `ffmpeg` และบน macOS ใช้ `swiftc` (Xcode Command Line Tools) สำหรับ OCR ถ้าจะใช้เสียง edge-tts หรือฟังกลับด้วย faster-whisper ให้ติดตั้ง [uv](https://docs.astral.sh/uv/) (`uvx` จะดึงแพ็กเกจมาเองตอนใช้ครั้งแรก)

จากนั้นพิมพ์ใน Claude Code เช่น *"ทำคลิปความรู้ภาษาไทยเรื่อง ทำไมบัญชีปลอมถึงโดนจับได้จากเลขตัวแรก"*

ทดสอบว่าโหมดภาษาไทยพร้อมใช้ (ออฟไลน์):

```bash
python3 skills/vibe-knowledge/tools/selftest_th.py
```

เครื่องมือหลักที่ใช้เอง:

```bash
python3 ~/.claude/skills/vibe-knowledge/tools/new_film.py 01 --template C --title "ก๋วยเตี๋ยวห้าบาทหายไปไหน" --lang th --series vk-th
python3 ~/.claude/skills/vibe-knowledge/tools/recommend.py "ก๋วยเตี๋ยวชามละห้าบาทหายไปไหน"
python3 ~/.claude/skills/vibe-knowledge/tools/duration.py --scores 1,0,2,1,1 --template C --lang th --backend edge-m
cd ~/vibe-knowledge && python3 scripts/tts_th.py examples/vk-th/lessons/01/narration.json examples/vk-th/lessons/01/build --backend edge
```

รายละเอียดทั้งหมดอยู่ใน [references/15-thai.md](skills/vibe-knowledge/references/15-thai.md)

## สไตล์

47 สไตล์ใน 9 กลุ่ม: 44 แบบเดิมจากต้นฉบับ (ทุกแบบมีชื่อและคีย์เวิร์ดภาษาไทยแล้ว) และกลุ่ม "ไทย" ที่เพิ่มใหม่ 3 แบบ

- **จิตรกรรมฝาผนังไทย** (`thaimural`): พื้นแดงชาด เส้นทอง เรื่องเล่าเป็นตอน ๆ คั่นด้วยสินเทา (ต้องสร้างภาพฉาก)
- **หนังตะลุง** (`nangtalung`): ตัวหนังฉลุลายบนจอผ้าแสงตะเกียง (โค้ดล้วน)
- **ป้ายร้านตลาดไทยย้อนยุค** (`thaisign`): ป้ายสังกะสีเขียนมือ ป้ายราคาพลิกตัวเลข (โค้ดล้วน)

ดูทั้งหมดที่ [styles/INDEX.md](skills/vibe-knowledge/styles/INDEX.md)

## ระดับเพิ่มพลังโดยไม่ต้องจ่าย

ต้นฉบับใช้ Renoise (ระบบเครดิต) สร้างภาพและคลิปสำหรับช็อตพิเศษ ฉบับนี้ให้ใช้เครื่องมืออะไรก็ได้: สร้างเองบนเว็บ, Grok Imagine, ComfyUI บนเครื่อง, เครื่องมือบรรทัดคำสั่งอื่น ๆ หรือ Renoise ก็ยังได้ จดไว้ในช่อง `engine` ของ `assets.json` แล้ววางไฟล์ใน `assets/img/` หรือ `assets/clips/` ([04-renoise.md](skills/vibe-knowledge/references/04-renoise.md) หัวข้อ "自带生成器")

## ข้อจำกัดและสิ่งที่ยังไม่เสร็จ

- สไตล์ไทยทั้ง 3 แบบยังไม่มีภาพตัวอย่าง (`still.jpg`) และยังไม่ได้เรนเดอร์คลิปตัวอย่าง
- Gemini และ MiMo ภาษาไทยยังไม่ได้ทดสอบจริง
- โหมดไทยครอบคลุมเอนจิน cine ที่ vibe-knowledge ใช้ ส่วนเอนจิน sketch / lesson ของ ai-teardown ยังเป็นภาษาจีน
- เอนจินเรนเดอร์ 16:9 เท่านั้น แนวตั้งใช้วิธีแปลงด้วย ffmpeg ใน [16-publish-th.md](skills/vibe-knowledge/references/16-publish-th.md)
- เวลา cue ของเสียงที่ไม่มีเวลาระดับคำ (say, Gemini, MiMo) ประมาณจากสัดส่วนตัวอักษร คลาดเฉลี่ยราว 0.2 วินาที
